# 09. Истории (Stories)

## 1. Обзор работы историй
Истории реализованы в двух компонентах:
- Горизонтальная лента `src/components/Stories/StoriesBar.tsx` (на главной странице).
- Полноэкранный плеер `src/app/stories/[id]/page.tsx`.

---

## 2. Загрузка и создание истории
1. В `StoriesBar` при нажатии на значок `+` на своем аватаре активируется выбор файла.
2. Поддерживаются форматы: `image/jpeg`, `image/png`, `image/webp`, `video/mp4`, `video/webm`.
3. Файл загружается в бакет `stories` Supabase Storage по пути:
   `${user.id}/${Date.now()}-${file.name}`.
4. В таблицу `stories` вставляется запись:
   ```ts
   {
     user_id: user.id,
     media_path: uploadedPath,
     media_type: file.type.startsWith('video/') ? 'video' : 'image'
   }
   ```
5. В случае сбоя записи в БД файл удаляется из Storage во избежание накопления «мусора».

---

## 3. Просмотр и таймеры в плеере (`/stories/[id]`)
- **Таймер прогресса**:
  - Фото: автоматический таймер длительностью **5 секунд**.
  - Видео: продолжительность подстраивается под реальный хронометраж видеоролика.
- **Пауза по зажатию (Hold to pause)**:
  - При зажатии кнопки мыши или пальца на экране (`onMouseDown`, `onTouchStart`) таймер останавливается, а видео ставится на паузу. При отпускании воспроизведение продолжается.
- **Временные ссылки**:
  - Так как бакет `stories` приватный, просмотрщик генерирует временный URL через `createSignedUrl(media_path, 300)`. Срок действия ссылки — 5 минут.
- **Просмотры и реакции**:
  - Открытие истории записывается в `story_views`.
  - Отправка смайликов (🔥, ❤️, 😂, 👏, 😮, 😢) записывается в `story_reactions`.
- **Удаление истории**:
  - Доступно только владельцу истории.
  - Сначала удаляется медиафайл из бакета `stories`, затем удаляется строка из таблицы `stories`.
