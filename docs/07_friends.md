# 07. Друзья

## 1. Взаимодействие с пользователями
Модуль реализован в `src/app/friends/page.tsx` и `src/components/FriendCard/FriendCard.tsx`.

### Вкладки управления:
1. **«Все друзья»**:
   - Показывает всех пользователей, с которыми есть подтвержденная связь (`status = 'accepted'` в таблице `friend_requests`).
   - Доступна кнопка перехода в чат («Написать сообщение»).
   - Доступно действие удаления из друзей (удаление строки из `friend_requests`).
2. **«Входящие заявки»**:
   - Запросы, где текущий пользователь является адресатом (`receiver_id = user.id, status = 'pending'`).
   - Действия:
     - **Принять**: обновление `status = 'accepted'`.
     - **Отклонить**: удаление записи из `friend_requests`.
3. **«Исходящие заявки»**:
   - Запросы, отправленные текущим пользователем (`sender_id = user.id, status = 'pending'`).
   - Действие: **Отменить заявку** (удаление записи).
4. **«Поиск пользователей»**:
   - Строка поиска выполняет фильтрацию по таблице `profiles` (по полям `username` и `display_name`).
   - Исключает самого себя.
   - Для каждого найденного пользователя отображается его статус дружбы: «В друзьях», «Заявка отправлена», «Принять заявку» или кнопка «Добавить в друзья».

## 2. Карточка друга (`FriendCard`)
- Используется на главной странице и в разделах рекомендаций.
- Отображает аватарку, индикатор онлайн/офлайн, статусное сообщение, текущий трек и шкалу прогресса.
- Кнопка **«🎧 Слушать вместе»**: при нажатии включает тот же трек в плеере текущего пользователя.
- **Особенность**: список друзей на главной странице и их текущие треки берутся из `src/data/mockData.ts`, в то время как поиск и заявки на странице `/friends` полностью работают через Supabase.
