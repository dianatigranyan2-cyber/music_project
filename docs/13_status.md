# 13. Статус разработки

Сводная матрица текущей готовности функционала проекта Melo по результатам анализа кодовой базы:

| Функция / Модуль | Статус | Что реализовано | Что предстоит сделать | Файлы в кодовой базе |
|---|---|---|---|---|
| **Регистрация и Вход** | **Готово** | Email + пароль, проверка уникальности username, валидация полей, сохранение сессии в куки и LocalStorage. | Восстановление пароля, вход через OAuth (Google, GitHub). | `src/context/AuthContext.tsx`<br>`src/app/login/page.tsx`<br>`src/app/register/page.tsx` |
| **Профиль пользователя** | **Готово** | Редактирование имени, bio, загрузка аватара в Storage `avatars` с валидацией размера (до 5 МБ) и типов файлов. | Автоматическое удаление старой аватарки из хранилища при замене. | `src/app/settings/page.tsx`<br>`src/app/profile/page.tsx` |
| **Публичные профили** | **Готово** | Страница `/profile/[username]`, поиск профиля, отображение статуса дружбы. | Реальные счетчики друзей и прослушиваний (сейчас статика). | `src/app/profile/[username]/page.tsx` |
| **Система друзей** | **Готово** | Вкладки: Все друзья, Входящие, Исходящие, Поиск пользователей. Отправка, принятие, отмена и удаление. | Интеграция онлайн-статуса и треков друзей с Realtime Presence. | `src/app/friends/page.tsx`<br>`src/components/FriendCard/FriendCard.tsx` |
| **Личные сообщения** | **Готово** | Realtime обмен сообщениями, статусы прочтения `read_at`, удаление, редактирование через RPC `edit_own_message`. | Индикатор набора текста («печатает...»), пагинация истории. | `src/app/messages/page.tsx` |
| **Ответы на истории в чате** | **Готово** | Отображение превью медиа, генерация signed URL (300 сек), плашка «История недоступна» для удаленных историй. | Мгновенное обновление плашки в реальном времени при удалении истории. | `src/app/messages/page.tsx` |
| **Истории (Stories)** | **Готово** | Загрузка фото/видео в Storage `stories`, таймер (5 сек / видео), пауза по зажатию, реакции, удаление медиа и записи. | Добавление текстовых подписей, автоматическая очистка просроченных файлов. | `src/components/Stories/StoriesBar.tsx`<br>`src/app/stories/[id]/page.tsx` |
| **Музыкальный плеер** | **Частично / Мок** | Полнофункциональный интерфейс плеера (плей/пауза, таймлайн, громкость, shuffle, repeat, мобильный режим). | Плеер работает на демо-данных с JS-интервалом. Нужно подключить реальный аудиостриминг. | `src/components/Player/Player.tsx`<br>`src/context/PlayerContext.tsx` |
| **Каталог треков и поиск** | **Мок** | Поиск по названию трека и автору по массиву `DEMO_TRACKS`. | Полноценная таблица треков в Supabase или интеграция внешнего музыкального API. | `src/components/Header/Header.tsx`<br>`src/app/explore/page.tsx` |
| **Комнаты (Rooms)** | **Мок / UI Прототип** | Страница `/room/[id]`: верстка комнаты, список участников, локальный чат комнаты, очередь треков. | Бэкенд комнат с синхронизацией воспроизведения через WebSockets/WebRTC и базой сообщений. | `src/app/room/[id]/page.tsx` |
| **Плейлисты** | **Мок / UI Прототип** | Интерфейс управления плейлистами, модальное окно создания плейлиста в локальном стейте React. | Создание таблиц `playlists` и `playlist_tracks` в базе данных Supabase. | `src/app/playlists/page.tsx` |
| **Серверный Proxy сессий** | **Готово** | Функция `updateSession` в `src/proxy.ts` для обновления кук через `@supabase/ssr`. | Интеграция в корневой `middleware.ts` Next.js. | `src/proxy.ts` |
