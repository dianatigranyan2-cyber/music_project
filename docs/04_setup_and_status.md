# 04. Установка, настройка и статус разработки

## 1. Запуск и настройка проекта

### 1.1. Зависимости и скрипты (`package.json`)
В проекте используются следующие скрипты:
```bash
npm run dev    # Запуск сервера разработки на http://localhost:3000
npm run build  # Сборка оптимизированного продакшн-бандла
npm start      # Запуск собранного продакшн-сервера
npm run lint   # Проверка кодовой базы линтером ESLint
```

**Ключевые зависимости**:
- `next`: `16.3.6`
- `react`: `19.0.0`
- `react-dom`: `19.0.0`
- `@supabase/supabase-js`: `^2.49.1`
- `@supabase/ssr`: `^0.6.1`

---

### 1.2. Переменные окружения (`.env.local`)
Для работы приложения необходим файл `.env.local` в корне проекта со следующими ключами:
```env
NEXT_PUBLIC_SUPABASE_URL=https://<your-project-id>.supabase.co
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=<your-anon-or-publishable-key>
```

> **Важно**: В проекте используется префикс `NEXT_PUBLIC_`, благодаря чему переменные доступны как на сервере, так и в браузере.

---

### 1.3. Пошаговая инструкция по развертыванию на новом компьютере

1. **Клонировать репозиторий**:
   ```bash
   git clone <repo-url> music_project
   cd music_project
   ```
2. **Установить зависимости**:
   ```bash
   npm install
   ```
3. **Настроить переменные окружения**:
   Создать файл `.env.local` и указать URL и Publishable/Anon ключ проекта Supabase.
4. **Подготовить проект в Supabase** (если создается новый инстанс):
   - **Таблицы**: создать таблицы `profiles`, `friend_requests`, `messages`, `stories`, `story_views`, `story_reactions` (структура детально описана в [02_database_and_security.md](./02_database_and_security.md)).
   - **Storage Бакеты**:
     - Создать бакет `avatars` с типом **Public**.
     - Создать бакет `stories` с типом **Private**.
   - **RPC Функция**: создать процедуру `edit_own_message` в SQL Editor.
   - **Realtime**: включить таблицу `messages` в публикацию `supabase_realtime`:
     ```sql
     ALTER PUBLICATION supabase_realtime ADD TABLE messages;
     ```
5. **Запустить локальный сервер**:
   ```bash
   npm run dev
   ```
   Открыть в браузере: `http://localhost:3000`.

---

### 1.4. Что хранится в Git vs Что существует только в Supabase

| Компонент | Где находится | Описание |
|---|---|---|
| Исходный код интерфейса (UI) | **В Git репозитории** | Все страницы `src/app`, компоненты `src/components`, хуки и стили |
| Демонстрационные треки и друзья | **В Git репозитории** | Файл `src/data/mockData.ts` |
| Файлы миграций `.sql` | **Только в Supabase** | В Git отсутствуют файлы миграций; создание таблиц выполнялось через веб-интерфейс Supabase |
| Учетные записи пользователей | **Только в Supabase** | Сервис `auth.users` в облаке Supabase |
| Файлы аватарок и историй | **Только в Supabase Storage** | В облачных бакетах `avatars` и `stories` |
| Realtime публикация и RLS | **Только в Supabase** | Правила безопасности и WebSocket шлюз |
