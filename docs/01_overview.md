# 01. Общее описание Melo

## Назначение проекта
**Melo** — это социальная музыкальная веб-платформа, которая объединяет стриминг музыки с социальными функциями: общением в реальном времени, публикацией историй (Stories), системой друзей и виртуальными комнатами совместного прослушивания (Rooms).

## Стек технологий
- **Фреймворк**: Next.js 16.3.6 (App Router)
- **Библиотека интерфейса**: React 19.0.0
- **Язык**: TypeScript 5
- **Стилизация**: Модульный CSS (`.module.css`), глобальные переменные (`globals.css`)
- **Бэкенд**: Supabase (PostgreSQL, GoTrue Auth, Realtime WebSockets, Storage)
- **Клиентские библиотеки**: `@supabase/supabase-js` (2.49.1), `@supabase/ssr` (0.6.1)

## Основные возможности
1. **Музыка**: воспроизведение треков в глобальном аудиоплеере без остановки при смене страниц.
2. **Личные сообщения**: мгновенный чат с поддержкой Realtime, отметками прочтения (`read_at`), редактированием через RPC (`edit_own_message`), удалением и ответами на истории.
3. **Истории (Stories)**: загрузка фото и видео в защищенное хранилище Supabase Storage, временные подписанные ссылки (signed URLs на 300 сек), автопроигрывание с таймером (5 сек для фото / длительность видео), пауза по зажатию (hold to pause), просмотры и реакции.
4. **Друзья**: поиск пользователей по юзернейму, отправка, принятие, отклонение и отмена заявок, удаление из друзей.
5. **Профиль**: настройка профиля, валидация уникального юзернейма, загрузка аватара с проверкой размера и формата.
6. **Комнаты и плейлисты**: прототипы комнат совместного прослушивания и управления плейлистами.
