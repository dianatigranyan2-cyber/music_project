# Музыкальная библиотека Melo

В каталоге 30 композиций: 15 Kevin MacLeod, альбом **Cylinders** Chris Zabriskie (9 треков) и 6 русскоязычных синт-поп песен **Sector 516** из альбома **«Чувствомер»**. Список — `music/CATALOG.md`, данные для импорта — `music/library.json`.

**Подключено 14 октября 2026:** миграция выполнена в проекте `music_project_melo`, все 24 аудиофайла загружены и записи опубликованы. Публичная проверка подтвердила количество, связи с исполнителями, размеры файлов, совпадение первых байтов и HTTP Range для всех треков. В браузере проверены MP3/M4A, поиск, страницы исполнителя/альбома, перемотка, очередь, автоматический переход к следующей песне и продолжение воспроизведения при навигации. Блокировка физического телефона пока не проверена.

**Дополнение 14 октября 2026:** загружены и опубликованы шесть песен Sector 516. В каталоге 30 записей; повторная проверка всех 30 аудиофайлов прошла. Интерфейс показывает настоящую лицензию каждой песни, без общей подписи CC BY 4.0 для всех источников.

## Где что хранится

- Аудиофайлы после подготовки: `.music-import/audio/` (MP3 и M4A, примерно 166 МиБ). Эта папка исключена из Git.
- После загрузки: Supabase Storage, публичный bucket `music-audio`. Сайт воспроизводит эти файлы напрямую из Supabase.
- Исполнители, альбомы, песни, длительности, пути к файлам и лицензии: таблицы `music_artists`, `music_albums`, `music_tracks`.
- Текстовые данные каталога и код входят в Git. Ключи и скачанная музыка — нет.

## Установка в Supabase

1. Выполнить `npm run music:prepare`. Скрипт скачивает только с разрешённых официальных доменов, проверяет размер и заголовок формата, сохраняет SHA-256. Завершённые загрузки можно безопасно использовать при повторном запуске. Снимки условий лицензий находятся в `.music-import/licenses/`.
2. Выполнить `npm run music:seed`. Скрипт проверит хеши файлов и создаст `.music-import/seed.sql`.
3. В SQL Editor своего проекта выполнить **`supabase/music_library.sql`**, затем **`supabase/music_library_licenses.sql`**. Будут созданы три музыкальные таблицы и bucket, добавлена поддержка точных пар CC BY 4.0 / CC BY-SA 3.0. Социальные таблицы не меняются.
4. В **Storage → music-audio → Upload files** выбрать файлы из `.music-import/audio/`. Загрузить в корень bucket, сохранив UUID-имена файлов. Не выбирать папку целиком: она не должна становиться вложенной папкой в bucket. При пополнении загружать только новые файлы.
5. После завершения всех загрузок выполнить **`.music-import/seed.sql`** в SQL Editor. Скрипт откажется публиковать каталог, пока всех объектов подборки нет в Storage. Повторный запуск не создаёт дубликаты.
6. Открыть `/explore`. Проверить 30 треков, трёх исполнителей и два альбома. Запустить трек, перейти на другую страницу и проверить продолжение воспроизведения.

Для сайта достаточно существующих `NEXT_PUBLIC_SUPABASE_URL` и `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`. Секретный service-role ключ не нужен в браузере и не должен попадать в исходники.

## Доступ

Посетители читают только опубликованные записи. Записывать каталог можно через доверенное администрирование проекта Supabase. Обычные пользователи не могут публиковать песни, менять исполнителя или перезаписывать/удалять музыкальные файлы. Ограничительные Storage-политики защищают музыку даже при наличии старых общих разрешений на загрузку; другие bucket они не ограничивают.

`is_published` управляет видимостью песни в каталоге. Публичный bucket предназначен только для аудио, которое разрешено распространять: знание URL позволяет скачать файл, даже если запись скрыта в каталоге.

## Что уже поддерживает приложение

- Каталог и поиск по названию, исполнителю и альбому; фильтр по реальному жанру.
- Страницы исполнителей и альбомов со связями по ID. Для Kevin MacLeod альбомы не выдумываются: эти записи представлены как синглы.
- Очередь, следующий/предыдущий трек, перемотка, громкость, повтор песни и случайный порядок.
- Один постоянный native audio-элемент в корневом контексте. Переходы внутри приложения не заменяют элемент; нет таймера, имитирующего звучание.
- Media Session для системных кнопок и метаданных там, где браузер поддерживает этот API.

Физическая блокировка телефона требует проверки на настоящем устройстве. Настройки энергосбережения и конкретный мобильный браузер влияют на фоновое воспроизведение. Полная перезагрузка страницы создаёт новый audio-элемент. Совместное прослушивание с друзьями — следующий отдельный этап.

## Как искать музыку

На компьютере: открыть **«Обзор»**, затем ввести название песни, исполнителя или альбома в верхнюю строку **«Поиск треков, исполнителей и друзей…»**. На телефоне: открыть **«Обзор»**, нажать **🔍** вверху и ввести запрос. Например: **«Кто-то рядом»**, **«Чувствомер»** или **Sector 516**. Поиск работает по уже опубликованной библиотеке Melo, а не по всему интернету.

## Добавление музыки позже

Новые треки требуют аудиофайла и подтверждённого права на размещение. Добавляются исполнитель (при необходимости), настоящий альбом (если есть), затем запись песни с лицензией, хешем и UUID-путём файла. Сначала загружается аудио, потом публикуется запись. Скрипты и формат `music/library.json` позволяют готовить следующую подборку пачкой. Автоматического получения новых релизов и интерфейса загрузки для обычных пользователей пока нет.

## Проверки

`npm run test:music` проверяет поиск, связи каталога, очередь и native audio события, включая запоздалые ошибки предыдущей песни. `node tests/check-music-db.mjs` проверяет SQL в отдельном временном PostgreSQL: повторное применение, публикацию только после загрузки, RLS, запрет записи для посетителей и связь альбома с его исполнителем.

`node scripts/check-music-remote.mjs` выполняет проверку опубликованной подборки только чтением: данные каталога, размеры аудио и частичные HTTP-запросы. Использует существующий публичный ключ из `.env.local` и не выводит его.

Для изолированной SQL-проверки: `npm install --prefix .music-import/db-check --no-save --package-lock=false --ignore-scripts @electric-sql/pglite`.
